This page came from html/index.html next to the lobo binary you just ran, through the stock conf/lobo.conf. That file is an nginx.conf: edit it the way you would edit nginx's, run ./lobo -t -c conf/lobo.conf to test it, and ./lobo -s reload -c conf/lobo.conf to load it into the running server without dropping a connection.

What is different from nginx — and what is deliberately the same — is in GETTING-STARTED.md and the docs/ directory beside this file.
